# 폴더 공유와 변경 이력

폴더 상세의 **공유 · 권한 관리**에서 참여자의 역할을 선택한다. 기존 일회용 코드 연결로 상대 계정을 확인하며, 소유자가 언제든 역할을 변경하거나 공유를 철회할 수 있다. 선택한 폴더만 공유하며 하위 폴더는 별도다.

| 방식 | 동작 |
| --- | --- |
| EXPORT · 사본 공유 | JSON 파일 전달. 받는 사람은 기억 가져오기에서 자기 소유의 비공개 폴더 사본을 생성한다. 이후 원본과 동기화하지 않는다. |
| 열람 전용 | 내용·변경 이력 조회와 사본 내보내기 가능. 원본 수정·삭제·복원 불가. |
| 편집 · 공동작업 | 기억·인수인계·폴더 이름·작업 진행 내용 수정. 변경 이력이 남고 이전 상태로 복원 가능. |
| 소유자 | 위 기능과 참여자 권한 관리, 폴더 간 이동, 폴더 전체 영구 삭제. |

공유용 EXPORT에는 컴퓨터의 로컬 경로·연결 키·접근 권한을 담지 않는다. 내보낸 현재 폴더의 이름, 인수인계, 기억, 작업 내용이 사본으로 복사된다. 원래 기록 ID·계정·권한·과거 이력을 파일 내용만 믿고 복원하지 않으며, 사본은 새 ID와 새 이력으로 시작한다. 진행 중이던 작업의 담당 예약은 복사하지 않고 대기로 전환한다. 일반 계정 내보내기는 변경 이력의 읽을 수 있는 스냅샷도 포함한다.

## 복원

**변경 이력 · 복원 → 변경 선택 → 변경 전/후 비교 → 상태 복원** 순서로 사용한다. 사용자 이름, 작업 종류, 시간, 버전을 표시한다. 복원 시 공유 권한, 에이전트 허용, 로컬 프로젝트 연결은 되돌리지 않는다.

- 기억 수정, 승인 상태 변경, 추가 취소, 삭제된 기억 복구, 소유자의 폴더 간 이동 복원
- 폴더 이름·인수인계 복원, 소유자의 상위 폴더 이동 복원
- 작업 진행 보고·삭제 복원. 과거 담당/예약은 재활성화하지 않으며, 현재 진행 중인 작업은 담당 해제 후 복원
- 기존 기억 버전 화면의 **이 버전으로 복원**으로 이전부터 남아 있던 본문 버전도 복구

복원은 기존 이력을 삭제하는 것이 아니라 새 버전을 추가한다. 상세 조회 이후 다른 사람이 수정하면 복원을 거절하고 최신 상태를 다시 확인하도록 한다. 이동된 항목은 양쪽 폴더의 소유 권한을 확인하며, 비공개 목적지의 경로·본문을 이력 상세에서 노출하지 않는다. 삭제된 기억 복구 시 원래 ID와 남겨 둔 이전 버전도 복구한다.

새 폴더 변경 로그는 V5 적용 이후부터 기록한다. 이전에 영구 삭제되어 남아 있지 않은 내용은 복구할 수 없다. **소유자가 별도 확인 후 실행하는 폴더 전체 영구 삭제는 해당 폴더 이력도 지우며 복원 대상이 아니다.** 공유받은 편집자는 이 작업을 실행할 수 없다. 계정 삭제 역시 해당 소유자의 이력을 함께 삭제한다.

## 구현과 검증

`folder_history`에 변경 전·후 스냅샷을 암호화하여 동일 DB 트랜잭션에서 저장한다. 공유받은 사용자는 로그를 덮어쓰거나 삭제하는 API를 갖지 않는다. 변경 이력도 저장 공간 사용량에 포함된다. 복원은 현재 revision과 entity의 마지막 변경 sequence를 함께 확인하여 삭제/재생성 과정의 오래된 복원 요청도 거절한다. 복원 이력 역시 같은 방식으로 기록한다.

Java 통합 테스트는 공동 편집, 암호화, 열람 차단, 권한 철회, 충돌, 삭제·이전 버전 복구, 이동 권한, 작업 이력, 사본 독립성을 검사한다. 브라우저 테스트는 두 계정의 편집→소유자 복원→열람 전용 변경→EXPORT 다운로드→비공개 사본 가져오기를 검증한다. PostgreSQL 검증은 V5 업그레이드, 재시작 후 복원 이력 유지와 계정 삭제 시 이력 정리를 검사한다.
