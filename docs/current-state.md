# 현재 구현 상태 (2026-09-18)

현재 제품은 개별 계정으로 프로젝트 기억을 정리하고 공유하는 서비스입니다. 블록체인·지갑 로그인·온체인 권한·앵커 기능은 제거했으며 향후 구현 계획에도 포함하지 않습니다.

## 구현

- 계정 가입/로그인/복구/삭제, DB에 저장하는 로그인 세션.
- Claude/Codex 기억 파일·폴더 선택 → 전체 본문·제목 유사도로 자동 분류 → 승인 없이 저장. 같은 내용 중복 방지, 다른 버전 원문 보존.
- 폴더·기억 편집, 버전 이력, 인수인계 문서. 에이전트 업데이트 제안은 별도 승인.
- 서버가 발급하는 12자리 일회용 공유 코드. 받는 계정 입력 후 소유자가 상대 계정과 같은 코드를 확인해야 공유 완료. 만료 10분, 취소·재발급·재사용 방지·시도 제한.
- 폴더별 비공개/공유 상태·읽기/편집 권한·철회. 기존 MCP와 로컬 경로 연결은 유지하며, 신규 연결은 현재 API 설정 필요.
- PostgreSQL 영속 저장, AES-GCM 원문 암호화, 백업·복원.
- 요금제 사용량/한도 및 Stripe 어댑터. 실결제는 미활성.

기존 초대 링크는 업그레이드 시 무효화됩니다. 기존 완료된 폴더 공유는 유지됩니다. 코드 연결은 계정 사이의 공유이며 컴퓨터 하드웨어를 인증하는 방식은 아닙니다. 공유된 권한은 코드 만료 뒤에도 철회할 때까지 유지됩니다.

## 실행과 남은 작업

`APP_MODE`는 `demo`와 `service`를 지원합니다. 현재 PC 서버는 localhost에서만 접속할 수 있습니다. 다른 PC에서의 접속에는 공통 서버 접속 경로·HTTPS 설정이 필요합니다. 도메인·요금·결제 공급자 확정과 실제 결제 검증, Windows 부팅 후 WSL 자동 시작은 남아 있습니다.

자동 대화 수집/선별, 긴 세션 자동 복원, 실제 임베딩 품질 평가는 후속 작업입니다. 유료 AI API 응답과 공개 인터넷 서비스를 검증했다고 표현하지 않습니다.

[PC 서버](pc-server.md) · [사용법](service-guide.md) · [검증 안내](testing.md)

폴더 첫 화면은 날짜별 작업 타임라인입니다. 원문을 바탕으로 짧게 정리하며 원문은 상세에서 확인합니다. 새 기억 작성·기존 복사·고급 자동 연결 UI는 제거했습니다. 기존 MCP 연결은 유지되지만 신규 연결 설정 화면은 별도 제공하지 않습니다.

최신 폴더 UX: 제목 중심 격자 → 폴더 상세 → 날짜별 작업 타임라인 → 기록/원문. 원문 메타데이터와 경로를 요약에서 제외하고 요청·결정·작업보고·계획을 구분합니다. 원문 기반 정리이며 AI 종합 요약은 아닙니다.
