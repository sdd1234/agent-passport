## 상태 표시 규칙

- **현재 적용**: 현재 소스에서 동작하는 기능. 실행 설정에 따라 활성화 여부가 다를 수 있습니다.
- **검증 완료**: 해당 조건에서 실제 테스트한 기능. 로컬 EVM, 고정 벡터, 실제 모델 호출을 구분합니다.
- **추가 설계**: 이 문서에 제안한 구조. 코드나 DB에 이미 반영된 것으로 해석하지 않습니다.
- **미검증**: 코드가 있어도 실제 외부 서비스/품질을 확인하지 않은 항목입니다.

문서 작성 과정에서 기능을 켜거나 DB·권한·전역 Agent 설정을 변경하지 않았습니다. 다음 구현 단계의 완료 여부는 실제 코드와 검증 결과를 기준으로 갱신해야 합니다.
