# 서버 기반 협업 서비스 구현 상태

2026-09-17 사용자 확정 목표: Codex·Claude의 기억을 프로젝트별로 정리하고 서버에 저장하며, 요금제와 폴더 공유로 다른 작업자가 이어받는 실제 서비스.

## 구현됨

- 개별 사용자 가입/로그인, PBKDF2 비밀번호, DB 영속 세션, 복구 코드, 로그아웃/데이터 내보내기/탈퇴.
- 로컬 Codex·Claude 기억/선택 대화 내보내기, GUI 미리보기·내용 수정·선택·프로젝트별 폴더 생성/분류, 중복 방지와 승인.
- 프로젝트/하위 폴더 생성·수정·이동·삭제, 기억 편집·검색·승인·버전 이력·이동·삭제, 인수인계 문서.
- 1회/24시간 초대, 기존 계정 공유, viewer/editor 역할, 공유 철회, 소유자 경로 비공개.
- 사용자별 로컬 경로 매핑, 에이전트별 명시적 허용, MCP 폴더 컨텍스트·검색·업데이트 제안, 검토 전 조회 차단.
- Free/Pro 서버 한도·사용량 집계·롤백, Stripe Checkout/포털/서명 검증·멱등 웹훅·현재 상태 조회·주기적 재확인.
- PostgreSQL/Flyway, 프로덕션 HTTPS Compose, 백업/복원 스크립트, CI 템플릿과 합성/실제 클라이언트 검증.

## 검증과 운영 경계

[사용법](service-guide.md), [배포 절차](deployment.md), [검증 결과](service-validation.json)를 참고하세요. H2 API, 브라우저 두 계정, 실제 PostgreSQL과 새 폴더 MCP를 검증했습니다. 실제 Codex/Claude의 폴더 조회 및 공유 철회 차단도 별도 로그인된 CLI로 검사했습니다. 일반 모델이 모든 세션에서 자동으로 도구를 호출한다는 뜻은 아닙니다.

운영 서버/도메인/결제 계정과 정식 가격이 아직 제공되지 않았습니다. PC/WSL loopback 서비스는 실제로 실행했고 재시작·영속성도 확인했습니다. 공개 HTTPS 배포와 실제 결제는 미완료입니다. 로컬 검증을 운영 서비스 완료로 표시하지 않습니다. 요금제 한도의 개발 기본값을 확정된 판매 조건으로 표시하지 않습니다.

## 별도 확장 범위

지속적인 대화 자동 감시, AI 중요도 선별, 자동 요약/긴 세션 복원, 의미 기반 중복 병합, 폴더 권한 상속, 외부 조직 SSO/이메일 초대, 다른 결제 공급자, RAG 품질 평가 및 공개 EVM 테스트넷은 별도 확장입니다. 현재는 명시적 가져오기와 도구 호출·사람 승인 방식입니다. 기존 RAG/EVM 설계·검증 문서는 여전히 해당 범위에 유효합니다.
